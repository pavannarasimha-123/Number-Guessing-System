# 🎯 Number Guessing System

A simple, interactive browser game where the player guesses a randomly generated number and gets instant feedback after every attempt.

🔗 **Live Demo:** [number-guessing-system.vercel.app](https://number-guessing-system.vercel.app)

## ✨ Features
- Random number generated on every new game
- Instant feedback: too high, too low, or correct
- Attempt tracking
- Restart and play again
- Lightweight: no frameworks, no dependencies
## 🧠 How It Works

1. The system picks a random number within a fixed range.
2. The player enters a guess.
3. The game compares the guess with the secret number and responds with a hint.
4. This repeats until the player guesses correctly.
